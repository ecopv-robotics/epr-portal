# EPR Portal 产品需求文档

## 1. 产品目标

为企业客户提供 EPR 注册申请递交、资料管理与状态跟踪入口。MVP 采用严格的一对一模型：一份递单只对应一个公司、一个国家、一个 EPR 服务项目。

## 2. 用户流程

登录 → 我的递单 → 新建递单 → 选择国家 → 选择服务 → 创建草稿 → 填写资料 → 提交申请 → 查看状态。

## 3. MVP 范围

Phase 1：项目初始化、数据库、JWT 登录、递单列表、国家/服务选择、新建草稿。

Phase 2（已完成）：50 个欧洲国家目录、四类服务、动态模板、公司/法人/店铺/产品资料、历史公司资料复用、本地文件上传。

Phase 3（已完成）：提交完整性校验、资料锁定、状态流转、状态历史和后台审核接口。

Phase 4（预留）：AI 审核、OCR、自动注册 Agent。

## 4. 核心规则

1. 一份递单 = 一个公司 + 一个国家 + 一个服务；MVP 不支持多国家或多服务。
2. 国家与服务共同决定产品字段、表单字段和材料要求；Phase 2 必须读取模板配置，业务代码不得按国家写条件分支。
3. 仅公司信息和法人信息可从历史企业资料复用。
4. 店铺信息绑定递单，必须重新填写，不从企业资料复用。
5. 产品信息绑定递单且使用 JSON 保存动态字段，不复用。
6. 国家服务材料绑定递单与材料要求，不复用。
7. 用户只能查看和操作自己的递单。

## 5. 状态

- `DRAFT`：草稿，可编辑。
- `SUBMITTED`：已提交，等待处理。
- `REVIEWING`：审核中。
- `NEED_FIX`：待补资料。
- `COMPLETED`：已完成。

Phase 1 创建的递单默认进入 `DRAFT`。

## 6. 非功能要求

- React 18、TypeScript、Vite、Ant Design；蓝白企业后台风格。
- FastAPI、SQLAlchemy、Pydantic、PostgreSQL、JWT。
- 文件存储经抽象接口接入；首版本地存储，未来可替换 MinIO、OSS、S3。
- 密码仅保存强哈希；接口按用户隔离数据；上传文件需在 Phase 2 校验类型与大小。

## 7. 验收标准（Phase 1）

- 演示账号可登录，错误密码返回 401。
- 未登录不能访问递单接口和页面。
- 用户可查看自己的递单列表。
- 用户选择一个国家和该国家的一项服务后创建唯一编号的草稿。
- 前后端构建/测试通过，README 可指导启动。

## 8. Phase 2 验收标准

- 国家目录包含 50 个广义欧洲国家，每个国家均配置 WEEE、电池法、包装法、一次性塑料。
- 产品字段和材料清单从 `service_template` 关联配置读取，前端不按国家硬编码。
- 六步资料页支持公司、法人、店铺、产品、材料和确认预览。
- 历史资料只复用公司及法人；店铺、产品和材料保持空白。
- PDF/JPG/JPEG/PNG 可上传到本地存储，单文件不超过 20MB。
- 每份递单绑定创建时所用模板版本。

## 9. 企业、法人及店铺字段规则

- 公司注册地分为中国大陆、中国香港、欧盟、其他公司，选择后切换公司类型选项和证明材料。
- 中国大陆公司要求营业执照和企业信用报告；中国香港公司要求 CR、BR、NNC1/NAR1，并支持补充董事索引；欧盟和其他公司要求注册证明，且填写本国 VAT 税号。
- 法人资料包含证件类型、性别、中英文/拼音名、联系人邮箱和电话、证件文件及拼音签名。身份证要求人像面与国徽面，护照要求资料页。
- 店铺资料包含销售平台、店铺链接、英文公司名称、英文注册城市、邮编、英文注册地址和后台截图。
- 店铺后台截图只允许 JPG/JPEG/PNG/WEBP，最大 2MB；其他身份与企业材料按界面提示限制为 20MB。

## 10. Phase 3 验收标准

- 客户只能在 `DRAFT` 或 `NEED_FIX` 状态编辑和上传资料。
- 提交时后端独立校验公司、法人、店铺、产品动态必填字段和全部必填材料，并一次返回缺失项。
- 草稿提交后进入 `SUBMITTED`；管理员接单后进入 `REVIEWING`。
- 管理员可从审核中转为 `NEED_FIX` 或 `COMPLETED`，要求补件时审核意见必填。
- 客户补件后重新提交，状态从 `NEED_FIX` 回到 `REVIEWING`。
- 每次状态变化记录原状态、目标状态、操作人、意见和时间。
- 普通客户不能访问后台审核 API。

## 11. 德国 WEEE 产品字段

德国 WEEE 使用国家与服务组合的专用动态模板，依次包含：产品类别（必填）、产品名称（必填）、对应的品牌logo（必填）、单边最大尺寸cm（必填）、预计销售量（选填）。

产品类别为下拉选择：热交换设备、屏幕设备、气体放电灯、非气体放电灯、大型设备（单边尺寸大于 50cm）、小型设备（单边尺寸小于 50cm）、小型信息和电信设备、大型光伏（单边尺寸大于 50cm）、小型光伏（单边尺寸小于 50cm）。类别选项由 `form_field.options` 提供，前后端均不得另行硬编码国家判断。
