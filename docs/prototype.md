# 页面原型说明

附件原型仅作为视觉参考；最终交互以 PRD 与接口设计为准。

## 全局布局

- 蓝白企业后台视觉，白色内容卡片、浅灰页面底色。
- 登录后左侧固定菜单，顶部显示品牌口号、通知入口和用户菜单。
- Phase 1 激活“我的递单”；企业资料和个人中心作为后续入口展示禁用态。

## `/login`

桌面端双栏布局：左侧品牌与合规价值主张，右侧登录卡片。字段为手机/邮箱、密码、记住我和登录按钮；错误在表单上方直接反馈。移动端隐藏品牌装饰区。

## `/applications`

页头包含标题、说明和主按钮“新建递单”。内容卡片包含状态筛选、关键词搜索和表格。列：申请编号、公司、国家、服务、状态、提交时间、操作。空状态引导创建首份申请。

## `/application/create`

顶部三步进度：选择国家和服务、填写资料、提交完成。当前 Phase 1 实现第一步：国家下拉框与服务卡片单选。提交后创建草稿并进入资料页占位界面。

## `/application/:id/form`（已实现）

左侧步骤：公司信息、法人信息、店铺信息、产品信息、材料上传、确认提交。公司信息提供“资料复用”弹窗；弹窗明确提示只复用公司及法人资料。产品字段和材料上传清单完全由模板返回。

资料页采用固定工作区卡片：左侧为垂直步骤和完成度，右侧为当前表单。每一步支持独立保存；产品可动态增删；材料表展示必填性、格式、上传状态和重新上传操作。确认页聚合公司、法人、店铺、产品及材料完成情况。正式提交按钮留待 Phase 3。

## 响应式

小屏隐藏固定侧栏，页头操作、工具栏改为纵向排列，创建页服务卡片改为单列。Phase 2 应补充移动端导航抽屉。
